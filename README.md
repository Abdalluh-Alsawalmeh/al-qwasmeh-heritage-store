# دار مطرزات القواسمة — Al Qwasmeh Heritage Store
A Full-Stack MERN E-Commerce Platform specializing in authentic handmade Palestinian and Jordanian traditional thobes and abayas.

##  Tech Stack
- **Frontend:** React.js, Tailwind CSS, Vite, Lucide React, React Router Dom
- **Backend:** Node.js, Express.js (MVC Pattern), Multer, JWT, Bcryptjs
- **Database:** MongoDB (Mongoose ODM)

##  Core Features
- **Full CRUD:** Create, Read, Update, and Delete products with device file upload (`multer`).
- **Authentication & RBAC:** User and Admin roles with secure JWT authentication and password hashing.
- **Client-Side Routing:** Full SPA architecture with route parameters (`/product/:id`) and URL-driven filters.
- **Search, Filter & Pagination:** Live multi-field keyword search, category filtering, and paginated product grid.
- **Direct Ordering:** WhatsApp API integration with customized order payloads.

##  Installation & Setup

### 1. Backend Setup
```bash
cd alqwasmeh-store-back
npm install
npm run dev # Runs on port 5000
```
### 2. Frontend Setup
```bash

cd alqwasmeh-store
npm install
npm run dev # Runs on port 5173
```
